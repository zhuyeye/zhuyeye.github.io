深圳北 → 景德镇北

高铁抵达后直接打车去酒店。以实际车次为准，国庆票开售即买。

入住与晚餐

不再安排景点。可就近吃冷粉、牛骨粉或油条包麻糍。

02

Thursday · Ceramic city

景德镇：博物馆到陶溪川

住 · 景德镇
09:00—11:30
中国陶瓷博物馆

重点看陶瓷史、名窑展和“无语佛”。免费实名预约，建议抢开馆后的早场。

11:30—13:00
陶阳里周边午餐

安排赣菜或当地小吃，午后继续步行与打车结合。

13:00—16:00
御窑博物馆＋陶阳里

看红砖建筑、御窑遗址和历史街区。门票 / 预约以官方页面为准。

16:30—21:00
陶溪川文创街区

逛老厂房、手作瓷器和夜景，晚餐在街区解决。公共街区通常免票。

交通：网约车为主预约：中国陶瓷博物馆
03

Friday · Move south

景德镇半日 → 三清山

住 · 三清山
09:30—11:30
雕塑瓷厂

买小件陶瓷，安排手作体验；若有乐天市集，以当日官方公告为准。

12:00—13:30
午餐、回酒店取行李

退房后前往车站或上车点。

14:00—19:00
景德镇 → 三清山港首索道附近

优先查询景德镇北→玉山南，再包车去民宿；若高铁接驳不顺，三人直接包车前往，抵达后办理入住。

交通：高铁＋山路包车住：港首索道附近
04

Saturday · Mountain day

三清山经典白天环线

住 · 上饶
06:00—07:00
退房寄存 → 港首索道

行李寄存在民宿，只带水和当天装备；提前约车前往港首索道，确认索道当日开放。

07:00—08:30
港首索道上山 → 西海岸

选择“港首上行、金沙下行”的跨索道组合，排队和接驳时间按国庆客流预留。

08:30—13:00
西海岸 → 三清宫 → 阳光海岸

先走西海岸高空栈道，再经三清宫转阳光海岸；途中安排山上简餐。

13:00—16:00
南清园：东方女神 → 玉台 → 巨蟒出山

沿经典观景点向金沙方向走，按体力删减支线，不在山上走回头路。

16:00—19:00
金沙下山 → 取行李 → 上饶市区

提前约车从金沙索道下站回民宿取行李，再直达上饶；索道和山路时间以当天公告为准。

19:30—21:00
入住 → 信江江滨 / 双塔公园

先办理入住，再安排轻松的江边夜走和晚餐；若下山晚则直接休息。

路线：港首上 / 金沙下住：上饶高铁站片区
05

Sunday · Lake city

上饶 → 杭州：龙井与西湖

住 · 杭州
07:30—09:30
上饶站 → 杭州东

优先购买直达高铁；上饶站酒店到车站很近，国庆建议至少提前45分钟到站。

10:30—12:00
酒店寄存行李、午餐

住龙翔桥 / 凤起路片区，下午去西湖西侧更顺路。

13:30—17:30
龙井村 → 九溪烟树

龙井村和九溪免费、不需预约。国庆道路拥堵，优先地铁接驳＋网约车。

18:00以后
西湖湖滨夜景

湖滨、断桥或西湖西线择一游览。

交通：高铁＋杭州网约车住：杭州龙翔桥 / 凤起路
06

Monday · Return

灵隐寺 → 杭州萧山机场

18:00 航班
06:30—09:30
灵隐寺＋飞来峰

尽量早到。灵隐寺香花券和飞来峰门票是两项，按官方页面分别确认。

10:00—13:00
西湖西线

曲院风荷、苏堤、花港观鱼三选一段，保留体力和行李时间。

14:00—16:00
取行李 → 萧山机场

18:00航班建议16点前到机场。国庆从市区到机场至少预留1.5小时。

返程：杭州萧山机场安全线：不晚于14:30离开市区

Book before you go

预约与购票节奏

现在
先锁可取消住宿

景德镇2晚、三清山山脚1晚、上饶1晚、杭州1晚。房型确认3位成人可入住，优先家庭房 / 双床房。

可执行
约9月中旬
12306分批开票

铁路通常提前15天售票，各车站起售时间不同。重点盯深圳北→景德镇北、景德镇北→玉山南、上饶→杭州东。

提醒
票务开放后
三清山门票＋跨索道组合

在“三清山旅游”官方渠道确认10月3日港首上行、金沙下行的单程组合是否开放；若不支持，现场咨询换乘规则并准备备用路线。

优先
预约开放后
中国陶瓷博物馆、御窑博物馆

前者通常免费实名预约；后者按官方页面购票或预约。国庆不要把热门馆安排到下午最后一场。

优先
杭州行前
灵隐寺＋飞来峰

灵隐寺香花券和飞来峰门票分开确认，选择10月5日早时段；西湖、龙井村、九溪本身不需要门票预约。

Before booking

出发前确认
